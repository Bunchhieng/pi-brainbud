// why brainbud

Built for deep work.

01
awareness
Context-aware

Reads your active file, imports, and recent commands. Every tip is specific to the stack you're actually using right now.

02
learning
Adaptive

Rate tips up or down. Liked topics resurface. Disliked ones vanish. The model steadily maps your knowledge gaps.

03
focus
Non-intrusive

Fires after a configurable idle window. Tips appear between prompts — zero interruptions mid-thought.

// commands

Simple controls.

> brainbud-tip
Force a tip immediately, without waiting for the idle trigger.
> brainbud-like
Rate the last tip up — steers future tips toward this topic.
> brainbud-dislike
Rate the last tip down — suppresses similar tips going forward.
> brainbud-last
Re-display the most recent tip in case you missed it.
> brainbud-history
List the last 10 tips with their titles and timestamps.
> brainbud-status
Debug snapshot — active context, config values, current model.
